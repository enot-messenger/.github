# Правила общения

## Чего ждём

- Уважительный тон: обсуждаем код и решения, а не людей.
- Конкретика вместо оценок: «этот запрос делает N обращений к БД» вместо «плохой код».
- Готовность объяснить решение и изменить его при появлении аргументов.
- Уважение к чужому времени: описываем контекст, прикладываем ссылки и шаги воспроизведения.

## Чего не делаем

- Оскорбления, унижение, дискриминация по любому признаку.
- Публикация чужих личных данных.
- Настойчивое продвижение изменений вне согласованного объёма проекта.
- Публикация внутренних данных проекта в открытых репозиториях и обсуждениях.

## Нарушения

Сообщайте владельцу организации через профиль GitHub. Обращение рассматривается конфиденциально. Меры — от предупреждения до отзыва доступа к организации.
