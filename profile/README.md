# Enot Messenger

Мессенджер с текстом, голосом и видео: личные чаты, небольшие группы и сообщества с текстовыми и голосовыми каналами.

Главная особенность — **сообщества размещаются на сервере владельца**. Переписка и файлы остаются у него, а платформа отвечает за аккаунты, адрес сообщества и подписку. Небольшие группы общаются напрямую между устройствами, сообщества — через медиасервер на VPS владельца.

## Платформы

Web (включая установку на домашний экран в iOS и Android), Desktop (Windows, macOS, Linux), Mobile (Android, iOS). Одна кодовая база, нативные оболочки вместо тяжёлого встроенного браузера — приложение не должно занимать сотни мегабайт оперативной памяти.
